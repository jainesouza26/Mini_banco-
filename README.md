# Nome do Projeto (Ex: MiniBancoV2)

O projeto se trata de um mini banco para o cliente ter acesso aos depósitos, saque e extratos facilitando o controle de suas financias.

## 🚀 Funcionalidades
- Cadastro de clientes e contas.
- Registro de transações bancárias (depósito, saque, transferência).
- Geração de relatórios associados ao titular da conta.
